# 烟雨江南 · 大规模扩建指导工程

本目录是一份可拆给其他AI逐项实现的完整建设说明：**8个主要Python框架文件、12区域规划、96资产提示词、16材质提示词、12公共系统任务、12组装套件任务**。总计148张任务卡，另附模块说明和接口文档。

本轮按用户要求只新增框架和大量具体指导；**未运行Blender、未生成扩建.blend、未进行画面调试**。Python是交接用初版框架，任务卡中的精细内容大多等待后续实现。

## 先打开这三个入口

1. [MASTER_GUIDE.md](MASTER_GUIDE.md)：整体风格、区域关系、文件职责和交接规则。
2. [TASK_INDEX.md](TASK_INDEX.md)：148张任务卡和对应文件，一次分配一张即可。
3. [HANDOFF.md](HANDOFF.md)：可以直接复制给下一位AI的接手指令。

## 目录用途

| 目录或文件 | 内容 | 当前状态 |
|---|---|---|
| `scripts/` | 8个主要Python文件，构造布局和初版几何并保留导出入口 | 已写，未做Blender运行验收 |
| `config/` | 12区坐标、数量、风格用途和17桥连接 | 已写的规划配置 |
| `catalog/` | 资产、材质、系统、套件、任务依赖图 | 后续实施清单，非成品统计 |
| `docs/` | 风格、坐标、连接、Python、材质、性能、交付说明 | 可供实现者读取 |
| `tasks/assets/` | 96项资产的具体生成与建模提示词 | 待逐项实现 |
| `tasks/districts/` | 12区的空间与用途指导 | 待逐项实现 |
| `tasks/materials/` | 16套材质的图像/PBR/接入提示词 | 待逐项实现 |
| `tasks/systems/` | 12项公共系统的接口与工作方法 | 待逐项实现 |
| `tasks/assemblies/` | 12种场景组合的摆放和连接提示词 | 待逐项实现 |
| `future/` | 对应的后续代码目录及文件命名表 | 已建说明，无精细资产实现 |
| `generated/` | 新模型、新图像、新报告的版本输出位置 | 目前仅输出说明 |

原仓库文件保持原样。本目录不自动运行旧生成器，不回写旧Jiangnan.blend，不把planned任务登记成validated。

未来运行命令见[输出说明](generated/README.md)。当前无需先执行；先按任务卡实施所需部分即可。
