# 材质槽与精细任务映射

| 初版槽 | 后续材质 |
|---|---|
| plaster | M01旧粉墙 |
| tile | M03黛瓦胎土 |
| timber | M04老木、M08树皮；二者细化时必须拆槽 |
| stone | M02青砖、M05铺地、M06驳岸；按对象用途细分 |
| earth | M14湿土 |
| water | 程序化水面，由S01与A094处理 |
| leaf | M15苔藓、M16叶卡，按植物部位拆分 |
| bamboo | M07竹皮 |
| cloth | M09粗麻、M10靛蓝 |
| paper | M11灯笼纸 |
| ceramic | M12粗陶 |
| iron | M13旧锻铁 |

初版颜色槽不包含任何已生成PBR纹理。只读参考旧textures中的图像时，先核实其实际用途、尺寸和是否可平铺；禁止从旧文件名推断已具备全部PBR通道。

底色sRGB、数据图Non-Color。雨水响应由湿度参数控制，阴影和高光不能烘进底色来取代光照。叶卡/布/纸的透明、透光、发光各有独立含义；实现者说明采用什么近似。
