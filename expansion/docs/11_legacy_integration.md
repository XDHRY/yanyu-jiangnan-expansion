# 与现有工程的衔接

读取基线为ai/asset-pipeline-v1。旧项目包含jiangnan.py、根Jiangnan.blend、tools内建筑/地面/道具/竹子/水岸生成器、asset_db和贴图管线。本轮新文件全部隔离到expansion，不重构旧入口。

旧生成器可能在main或reset中清空场景、重写文件；后续模型只读参考函数时先识别副作用，不通过import执行旧主函数来“获得资产”。实际复用可以读取旧资产包集合，或者在新的工厂里通过明确适配调用无副作用的几何函数。

D07旧庭院预留不是已经导入。S11将确定旧文件的实际尺寸、锚点、集合、材质/驱动依赖、相机和天空关系。确认后输出新组合文件，原文件保持只读。

新资产注册不直接写进旧asset_db；先用expansion/catalog。等用户明确进入整合阶段后再处理双注册表合并与CI接入，避免本轮扩建指导误改当前交付场景。
