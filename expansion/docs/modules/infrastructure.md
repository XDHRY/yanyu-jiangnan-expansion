# `infrastructure.py` · 桥梁与水埠骨架

对应已新增文件：[scripts/infrastructure.py](../../scripts/infrastructure.py)。本轮只提供初版框架，未运行Blender验收。

## 这个Python文件利用什么，实现什么

它使用math.sin与显式网格挤出。主要入口是`arch_bridge(builder, link) / build(...)`。输入相邻区桥跨、宽度、位置、方向；输出桥拱薄壳、栏柱、桥端socket与码头踏步。

实现方法：桥面按正弦纵剖面采样并封闭截面；两端高度与道路面一致，栏柱随拱高；码头用10级0.2米阶梯向水位下降。
