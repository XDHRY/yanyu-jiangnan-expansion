# `build_world.py` · 命令入口与输出

对应已新增文件：[scripts/build_world.py](../../scripts/build_world.py)。本轮只提供初版框架，未运行Blender验收。

## 这个Python文件利用什么，实现什么

它使用argparse、json、pathlib及上述模块。主要入口是`make_scene(config) / write_obj(builder, folder) / main()`。读取world.json，依次构造布局、地形、建筑、基础设施、物件，写OBJ/MTL或.blend及scene_manifest。

实现方法：先在内存创建完整图，再新建一个不存在的输出目录；OBJ烘焙根节点变换，Blender输出保留层级；拒绝覆盖已有目录。
