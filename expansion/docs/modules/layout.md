# `layout.py` · 地块与连接布局

对应已新增文件：[scripts/layout.py](../../scripts/layout.py)。本轮只提供初版框架，未运行Blender验收。

## 这个Python文件利用什么，实现什么

它使用纯Python，调用kernel.rng。主要入口是`make_layout(config) / overlaps(a,b)`。读取world.json的12区域；输出普通建筑地块、17桥连接与旧庭院保留框。

实现方法：地块候选为局部24米间距网格；排除北部地标预留区后，用区域独立seed打乱并截取所需数量；相邻区域中心相差180米才建立桥连接。
