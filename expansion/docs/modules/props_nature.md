# `props_nature.py` · 常见物体与植被骨架

对应已新增文件：[scripts/props_nature.py](../../scripts/props_nature.py)。本轮只提供初版框架，未运行Blender验收。

## 这个Python文件利用什么，实现什么

它使用截面放样、低边数旋转体与独立随机流。主要入口是`boat(builder, root) / build(builder, config)`。输入每区摊位、船、灯、树数量；输出小船、摊架、灯架、树冠和竹丛占位。

实现方法：船体由五个截面闭合连接；摊架由柱桌顶组合；竹子三竿成丛，树冠用渐缩体表示体积；植被限定在区域边带。
