# 几何层级与逐步替换

第一层是本轮源码骨架：明确布局、数量、主要轮廓和接口。它仍包含规则地块、共享厅堂拓扑、块状树冠与简化屋顶。

第二层由A001–A096实现真实构件、门窗、内腔、屋面、船壳、叶簇和地形细节。精细工厂应替换指定实例的几何，而保持asset_id、entry、road、water等外部契约。

第三层实现材质、UV、LOD、碰撞和天气。在第二层尚未稳定时，不把所有时间投入全景高采样；有单项需求可先对该项完成一版。

第四层组装K套件与D区域，检查路、门、桥、岸和视线。最后把旧庭院接入D07。每层完成状态分别记录，不用整体一句“完成”掩盖缺项。

此轮按用户要求不进行上述运行或反复微调。后续模型按分配任务执行一版，留下可供下一轮修正的结果。
