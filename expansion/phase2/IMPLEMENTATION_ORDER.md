# 二期实施顺序与可独立派发的工作

本轮只编写规格并提交，不执行以下步骤。用户以后可以一次选一个编号让其他模型实现。

## 基础协议

一期S02坐标、S03连接点、S04材质约定作为共同输入。先做P2-SI02的显式工厂注册和P2-SI12版本锁，再接需要运行的细化工厂；未实现这些系统时，单个模型仍可在独立测试场景里开发，但不要声称已接入全景。

## 三条可先完成的细化链

- 建筑：AD01台基转角→AD03柱础→AD04梁端→AD05檩条→AD06椽檐→AD10滴水瓦；再接AD15门、AD16五金和AD22门槛。
- 客栈：AD22标高过渡→IN06楼梯→IN02客房；IN01前厅、IN05后厨、DL09雨具、DL24门灯完成后，由ST03组成迎客场景。
- 渔埠：WH01船内壳→WH02船舷→WH03篷架；WH08托架、WH09系缆和DL21补网组成ST04生产片段。

## 其他专题

织染CP06→CP07；染缸CP08→CP09；陶作CP11→CP10→CP12→CP13→CP14；制纸CP15→CP16→CP17；雨伞CP18→CP19；制茶CP20→CP21。植物按主干/竹竿→枝叶→群落→LOD顺序。材质任务消费相应几何/工序来源后，再连接全局湿度。

ST01–ST12消费功能细节形成故事片段；最后读取districts内对应文件，把地区细化层与原地区组合。P2-SI17汇总真实覆盖，P2-SI18负责交接。

机器依赖表见DEPENDENCIES.json；它表达协议和已选的二期前置，相关一期父资产仍需按各任务输入实际确认。不要把目录顺序、编号大小或文件存在当作完成证据。
